# Godot-voxels — Custom Engine for YALE
Кастомная сборка **Godot Engine 4.7** с интегрированным и оптимизированным модулем **Voxel Tools** и средой **Jenova Framework**.
---
## 🛠️ Что включено и улучшено:
1. **Godot Engine 4.7 Source (`godot/`)**:
   - Актуальное ядро движка Godot с поддержкой современных графических пайплайнов и GDExtension.
2. **Модуль Voxel Tools (`godot/modules/voxel/`) с кастомными доработками**:
   - **Поддержка нестандартных и выступающих коллизий (Protrusion AABBs)**:
     - В оригинальном Voxel Tools коллизия блоков была строго зажата в рамках единичного куба `[0, 0, 0]..[1, 1, 1]`.
     - Добавлен расчет и учет вылетов AABB (`collision_box_extra_min`, `collision_box_extra_max`) в `BakedLibrary`.
     - Физический движок `VoxelBoxMover` теперь учитывает коллизии высотой 1.5 блока (заборы, частоколы, факелы), блокируя прыжки игрока и перемещение мобов.
     - Воксельный рейкаст (`raycast_blocky`) детектирует попадания по выступающим частям блоков и корректно возвращает целевой воксель для взаимодействия, разрушения и установки блоков.
   - **Оптимизированный BFS-движок воксельного освещения**:
     - Ускоренный пересчет прямого и блочного света.
3. **Jenova Runtime (`Jenova-Runtime/`)**:
   - Среда нативного C++20/C++23 скриптинга и горячей перезагрузки для Godot.

## 🚀 Как собрать движок на Windows:
### Требования:
1. **Visual Studio 2022** (с установленной рабочей нагрузкой *«Разработка классических приложений на C++»* / MSVC v143+).
2. **Python 3.10+** (должен быть в PATH).
3. **SCons**:
   ```cmd
   pip install scons
   ```
### Сборка редактора:
Просто запустите двойным кликом:
```cmd
build_editor.bat
```
Или выполните в командной строке:
```cmd
cd godot
scons platform=windows target=editor accesskit=no d3d12=no angle=no -j8
```
После завершения скомпилированный редактор появится по пути:
`godot\bin\godot.windows.editor.x86_64.exe`
