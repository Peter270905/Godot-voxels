# Godot-voxels — Кастомный движок для YALE

Кастомная сборка **Godot Engine 4.7** с глубоко модифицированным модулем **Voxel Tools** и встроенным фреймворком **Jenova Runtime**. Разработана специально для воксельной RPG на выживание **YALE**.

---

## 🌟 Ключевые фичи и улучшения:

### 1. Мягкое воксельное освещение в стиле Minecraft (Smooth Lighting):
* **Двухканальная модель света (Classic Minecraft Lighting)**:
  * **SkyLight (Солнечный свет)**: вертикальные лучи дневного света уровня 15, проходящие вниз сквозь воздух без потерь и рассеивающиеся вбок при контакте с землей и препятствиями.
  * **BlockLight (Блочный свет)**: свет от факелов, костров, лавы и светящихся грибов с радиусом затухания.
* **Smooth Lighting (Мягкое сглаживание по вершинам)**:
  * Плавная интерполяция освещенности между соседними вокселями на углах граней, убирающая резкие блочные стыки (аналог классического гладкого освещения из Minecraft / OptiFine).
  * **Ambient Occlusion (AO)**: объемное мягкое затенение на стыках стен, в углах и под выступами.
  * Реалистичные кривые нелинейного спада яркости (затухания).
* **Быстрый многопоточный BFS-движок**:
  * Алгоритмы распространения света на очередях (FastQueue / BFS) с минимальным оверхедом на процессор.

---

### 2. Поддержка выступающих коллизий (Protrusion AABBs):
* **Коллизии выше 1 блока (1.5x высоты и произвольные AABB)**:
  * В оригинальном Voxel Tools физические хитбоксы блоков были жестко ограничены рамками единичного куба `[0, 0, 0]..[1, 1, 1]`.
  * Добавлен автоматический расчет свесов (`collision_box_extra_min`, `collision_box_extra_max`) в библиотеке запеченных моделей `BakedLibrary`.
  * Физический контроллер `VoxelBoxMover` собирает окружающие воксели с учетом свесов. Заборы высотой 1.5 блока физически невозможно перепрыгнуть (высота прыжка игрока ~1.15 блока), что создает непреодолимые изгороди для мобов и игроков.
* **Умный воксельный рейкаст (`raycast_blocky`)**:
  * Луч игрока точно детектирует попадания по верхушкам и выступающим частям блоков (верхняя часть забора, высокие факелы и настенные декорации).
  * Возвращает точные координаты исходного вокселя и правильную нормаль грани для разрушения, подсветки контура и установки смежных блоков.

---

### 3. Jenova Framework (`Jenova-Runtime/`):
* Нативная интеграция C++20/C++23 скриптинга в редактор Godot.
* Горячая перезагрузка C++ модулей во время разработки без перезапуска редактора.

## 🚀 Как собрать движок на Windows:

### Требования:
1. **Visual Studio 2022** (с компонентом *«Разработка классических приложений на C++»* / MSVC v143+).
2. **Python 3.10+** (должен быть добавлен в системный PATH).
3. **SCons**:
   ```cmd
   pip install scons
   ```

### Сборка редактора в 1 клик:
Запустите файл:
```cmd
build_editor.bat
```
Или выполните вручную из папки `godot`:
```cmd
cd godot
scons platform=windows target=editor accesskit=no d3d12=no angle=no -j8
```

Готовый исполняемый файл редактора появится в папке:
`godot\bin\godot.windows.editor.x86_64.exe`
